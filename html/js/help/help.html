CleepDesktop

Installs, discovers and configures your Cleep devices. This page describes the main areas of the application.

The middle panel lists your Cleep devices. Devices on the local network are discovered automatically once they have started.

Devices appear in one list, sorted by name. Remote-access providers (when configured on the device) are shown next to the hostname.

Status icons:
  • offline (powered off or disconnected)
  • remote (reachable via the house gateway)
  • online
  • online with authentication enabled
Use the menu on a device for:
  • Device infos - installed apps and hardware details
  • Reload device page - refresh the device UI (when that device is open)
  • Refresh remote URL - update a public remote-access URL when available
  • Delete - remove the device from the list
The right panel shows the current page, for example:
  • Homepage
  • Device configuration (webview)
  • Cleep install
  • Monitoring
  • Updates, help, support, about
